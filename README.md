# NullMesh

A from-scratch C++ TCP and HTTP server for learning networking and systems programming.

## About

NullMesh is a systems programming project built from scratch in C++ to understand how network servers work at a lower level.

The project focuses on learning and implementing networking concepts rather than relying on high-level frameworks.

## Current Stage

### Stage 1 — TCP Server

Currently learning and implementing the foundations of a TCP server:

- Networking fundamentals
- IP addresses and ports
- Sockets
- TCP
- `socket()`
- `bind()`
- `listen()`
- `accept()`
- `recv()`
- `send()`
- Connection handling

## Planned Stages

### Stage 1 — TCP Server
Build the basic TCP server from scratch.

### Stage 2 — HTTP Server
Build HTTP handling on top of TCP.

### Stage 3 — Advanced HTTP Server
Explore more advanced server concepts, performance, concurrency, and robustness.

## Learning Philosophy

> WHY → HOW → CODE

Understand the problem first, then understand how the system solves it, and only then implement it.
